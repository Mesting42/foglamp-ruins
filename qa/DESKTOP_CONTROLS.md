# 桌面与触屏操作分离

日期：2026-10-21。

## 调整

- 电脑端使用独立的冲刺、雾灯、互动操作栏，默认键帽为空格、F、E。按钮可点击，冲刺和雾灯显示冷却秒数与进度；靠近可互动对象时互动按钮高亮。
- 键帽、按钮标签和无障碍快捷键信息跟随设置中的键位重绑更新。暂停后恢复 HUD 时保留当前冷却显示。
- 手机和平板继续使用左摇杆与右侧四个圆形按钮。
- 设备识别不再仅凭 `maxTouchPoints > 0` 或窗口宽度判断触屏。手机和平板平台保留触控布局；有精细指针和悬停能力的电脑优先显示键鼠布局，混合输入电脑可随实际鼠标、键盘、触摸输入切换。
- CSS 以统一 `touch-layout` 状态决定哪组控件显示，窄电脑窗口不会仅因为媒体查询切换到手机操作。
- 桌面动作通过统一输入帧处理，沿用冲刺冷却、乘船期间限制和附近对象的互动判定。
